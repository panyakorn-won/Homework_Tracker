# 📓 สมุดการบ้าน (Homework Tracker)

แอปติดตามการบ้าน — บันทึก **ชื่อการบ้าน**, **สถานะ (เสร็จ/ยังไม่เสร็จ)**, **วันที่สั่ง**, และ **วันที่กำหนดส่ง**
ทำเป็น PWA (Progressive Web App) ติดตั้งลงหน้าจอ iPhone ได้เหมือนแอปจริง โดยไม่ต้องผ่าน App Store

ข้อมูลถูกเก็บไว้ในเครื่อง (`localStorage`) เท่านั้น — ไม่มีการส่งข้อมูลออกไปที่ไหน และใช้งานได้แม้ไม่มีอินเทอร์เน็ตหลังติดตั้งครั้งแรก

---

## วิธีอัปโหลดขึ้น GitHub และเปิดใช้งาน

### 1. สร้าง repository ใหม่บน GitHub
- ไปที่ [github.com/new](https://github.com/new)
- ตั้งชื่อ repo เช่น `homework-tracker`
- เลือก **Public** (จำเป็นสำหรับ GitHub Pages แบบฟรี) แล้วกด **Create repository**

### 2. อัปโหลดไฟล์ทั้งหมด
อัปโหลดไฟล์ต่อไปนี้ทั้งหมดไว้ที่ root ของ repo (ลากไฟล์ทั้งหมดวางในหน้า "uploading an existing file" บนเว็บ GitHub ก็ได้ ไม่ต้องใช้ command line):
```
index.html
manifest.json
service-worker.js
icon-192.png
icon-512.png
```

### 3. เปิดใช้งาน GitHub Pages
- ไปที่ repo → **Settings** → เมนูซ้าย **Pages**
- ใต้ "Build and deployment" → Source เลือก **Deploy from a branch**
- Branch เลือก `main` และโฟลเดอร์เลือก `/ (root)` → กด **Save**
- รอประมาณ 1-2 นาที จะมีลิงก์ขึ้นมาแบบ:
  ```
  https://<ชื่อผู้ใช้>.github.io/homework-tracker/
  ```

### 4. เปิดในไอโฟนแล้วติดตั้งเป็นแอป
1. เปิดลิงก์ด้านบนด้วย **Safari** บน iPhone (ต้องเป็น Safari เท่านั้น ใช้ Chrome จะไม่มีปุ่มนี้)
2. แตะปุ่ม **แชร์** (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้น) ที่แถบด้านล่าง
3. เลื่อนลงแล้วแตะ **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. ตั้งชื่อแล้วแตะ **เพิ่ม**

จะมีไอคอนแอปสีน้ำเงินขึ้นบนหน้าจอโฮม เปิดแล้วจะเต็มจอเหมือนแอปจริง ไม่มีแถบ URL

## แก้ไข/ปรับแต่งภายหลัง

- แก้ไขข้อความ, สี, หรือฟิลด์เพิ่มเติมได้ในไฟล์ `index.html` (โค้ดทั้งหมดอยู่ในไฟล์เดียว: HTML/CSS/JS)
- หลังแก้ไขและ push ขึ้น GitHub ใหม่ ให้เปิดแอปในไอโฟนแล้วลากลงเพื่อรีเฟรช (หรือปิด-เปิดแอปใหม่) เพื่อดึงเวอร์ชันล่าสุด — ถ้าไม่ขึ้นให้ลบแอปแล้ว Add to Home Screen ใหม่อีกครั้ง

## ข้อจำกัด
- ข้อมูลเก็บอยู่ในเครื่องเท่านั้น หากลบแอปหรือเปลี่ยนเครื่อง ข้อมูลจะหายไป (ไม่มีระบบ sync ข้ามเครื่อง)
- ไม่มีการแจ้งเตือน (notification) เมื่อใกล้ถึงกำหนดส่ง — ฟีเจอร์นี้ต้องเพิ่มเติมภายหลังหากต้องการ
